# Enjeux 2027 pour les ports africains

| **Enjeu**                      | **Faits et conséquences pour votre organisation**                                                                                                                                                                               | **Thèmes**     |
|--------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|----------------|
| **Routes maritimes instables** | Août 2026 : environ 1,68 million d'EVP par Suez, soit +184 % sur un an mais −74 % par rapport à août 2023. Retour réversible depuis le conflit avec l'Iran (28 février 2026). Impact : repositionner le port.                   | 1, 3, Module A |
| **Décarbonation**              | Le cadre net-zéro de l'OMI n'est pas adopté ; une réunion d'adoption est prévue en décembre 2026. Impact : anticiper les investissements.                                                                                       | 1, Module B    |
